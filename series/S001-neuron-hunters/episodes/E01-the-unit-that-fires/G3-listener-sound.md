## 2. First-listen movement (no source vocabulary required)

What a first-time ear should be able to follow:

1. Something is heard that might be alive and might not.
2. One voice wants to name it. One voice refuses the name.
3. The work is a boundary: a living thing, and tools that watch / keep / stretch it — stretch left unanswered.
4. The question on the table is whether a signal can outlive whatever made it. Nobody answers.
5. They try to write the event down without claiming the writing *is* the living thing.
6. The machine makes a sound that does not settle yes or no.
7. The event does not come back. That absence is not death, not survival, not identity, not proof.
8. The last spoken law: heard ≠ named ≠ proven.

If a tester who has never seen the repo cannot retell those eight moves, the script is still too inward. G3 does **not** fix that by adding mythology. It fixes it by clarifying an I-line or a sound, or by cutting a source-term that leaked.

## 3. Sound objects vs interpretation

Aligned to `sound-brief.md`. Each object may **present**. None may **conclude**.

| Object | Present as | Must not read as |
| --- | --- | --- |
| SIGNAL | short, repeatable, unsweetened burst; organism / noise / memory / wish all still possible | heartbeat, creature call, coded message, “alive” synth |
| Index tone | small, dry, once near top | UI tutorial, countdown, mission accept |
| Room hiss | constant bed, low | dread score, omen swell |
| Breath / dry room | FIELD proximity | intimacy-as-identity |
| Apparatus | mechanical start / mark / return tone | success chime, fail buzzer, lock-on |
| Return tone | deliberately uncaptioned; same vocabulary as neither yes nor no | major-key confirm or error sting |
| Trace under hiss (sc.5) | optional, quieter than SIGNAL, not a second firing | ghost, afterlife, memory-proven |
| Silence after proof-shaped lines | longer than the line | “meaningful” music fill |
| Final absence | SIGNAL does not return; room continues | death stinger, fade-to-heaven, sequel button |

**Accident test:** mute the dialogue and play only the sound bed. If the bed alone says “it lived,” “it died,” “it was a neuron,” or “the machine worked,” the bed has interpreted. Redesign the sound, not the law.
